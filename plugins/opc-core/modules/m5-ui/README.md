# M5 界面优化

开关标识是 `m5-ui`，由外壳读取。本目录只有说明。

页面、侧栏分组和状态条在 `client/`，分组文件读取在 `server/ui.ts`，规则在 `shared/ui.ts`。不要把 `.ts` / `.tsx` 留在本目录。

分组优先读 `/home/br1efx/notes/cards/_ui/groups.yaml`，其次 `.yml`、`.json`。没有文件时用内置分组。插件只读这个目录，不写卡片。权限清单里 `m5-ui` 已启用，不联网。

顶部状态条读已有网关快照，缺数据写「暂无数据」。老人模式在父亲的面板默认开，在你的面板默认关，两边都能手动改，记在各自面板上。

决定见 `adr/0009-d7-ui-polish.md`。
