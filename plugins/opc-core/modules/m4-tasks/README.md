# M4 任务与工作流

开关标识是 `m4-tasks`。页面、模板解析和步骤推进在 `client/`、`server/`、`shared/`，这个目录只放说明。

三条模板在 `shared/workflows/`：开发流、视频流、内容流。运行时复制到 `/home/br1efx/notes/cards/_workflows/`，已有文件不覆盖。卡片墙可以「转成任务」或「从模板起任务」。进入待验收或完成前必须有证据。失败两次后改派攻坚，再失败会诊，再失败生成决策卡。

定时任务只生成未启用的命令，不在插件里调用守护进程。会话清理只归档带标记或已登记的会话，不删除。决定见 [adr/0006](../../../adr/0006-d5a-tasks-workflows.md)。
