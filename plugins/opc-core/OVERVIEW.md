opc-core is the shell of opc-os, a Paseo plugin for a one-person company workspace.

This revision adds the home screen 一人公司 OS, plus settings and notifications. Home lists modules M1–M6 and can turn each one on or off. A module that is off does not appear in the sidebar. The six module folders are notes only. They do not read files or contact a network. `permissions.manifest.json` records that empty file and network access.
