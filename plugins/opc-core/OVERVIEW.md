opc-core is the shell of opc-os, a Paseo plugin for a one-person company workspace.

This revision keeps the home screen, settings, notifications, and module switches. Notes open in the file panel: on desktop, Markdown and canvas files are editable; on mobile the canvas is read-only. `/收集` files a page into the inbox. The card wall reads `/home/br1efx/notes/cards/` and shows how many cards are waiting. Ticket cards count as waiting only in a person stage. The tasks screen starts work from a template, shows stuck cards, and shows the intake panel. Scheduled commands are created disabled. The gateway screen reads Magpie on 127.0.0.1 when probing is on, and shows a labeled mock spend when it is off. `permissions.manifest.json` records Markdown and canvas read and write for the shell and for M1, notes-library paths, `~/.opc` and worktree paths for intake, card-directory read and write for M2, and card plus workflow, session, and schedule directories for M4. M1 does not enable network. The shell allows `127.0.0.1` and `api.github.com`. M5 reads only `/home/br1efx/notes/cards/_ui/` and does not enable network. The sidebar groups sessions by display name and icon, the top strip reads the existing gateway snapshot, and large type defaults on for dad and off for me. M3 and M6 stay disabled and declare no file or network access of their own.
