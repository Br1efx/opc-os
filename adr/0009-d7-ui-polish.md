# 0009 · D7 的界面优化

- 状态：已接受
- 日期：2026-11-01
- 相关：[0003](0003-d4-gateway-monitor.md)、[0005](0005-d3-card-wall.md)、[0007](0007-d5b-opc-intake.md)

## 背景

M5「界面优化」之前只有入口。侧栏要按显示名和图标分组，顶部要看见门卫、额度和主机负载，父亲的面板要能用更大的字和热区。Better Paseo、Sidebar Organizer、Title Style 的能力要收进 `opc-core`，这一版不卸载它们，也不改安装清单。

Paseo 0.14 的 `defineSettings` 只有 `host` 作用域。dad 和 me 是两台 daemon，各存一份设置。

## 决定

1. 仍在 `opc-core` 里做，不拆插件。不改 D3 卡片状态机，不改 D5 任务和接单语义。不接 Anthropic。Magpie 源码和密钥不进仓。本 PR 不改 registry pin。
2. 分组文件优先读 `/home/br1efx/notes/cards/_ui/groups.yaml`，其次 `groups.yml`，再 `groups.json`。没有文件时用 `shared/ui/groups.yaml` 的内置文本。插件只读，不写卡片。符号链接不跟随，超过 256KiB 拒绝。非法配置用中文说明，不把坏文件当成成功，坏的 YAML 也不退回 JSON。改文件后刷新即生效。
3. 分组按 id、`opc-role` 或标题精确匹配，顺序小的优先。空组也显示。至少包含总秘书、主力开发、攻坚、调度员、写作，以及术语表里的其余显示名。未匹配进「其他」。`archivedAt` 非空或 `status === closed` 的会话进「已完成」，默认折叠。内部 Agent 不进列表。等你回复的会话排在组内前面，标题加「· 等你」。
4. 标题样式只做字重、颜色和前缀图标，写在同一份分组文件里。字重是常规、中等、半粗、粗体。颜色是强调色、正文色、弱化色。不调用模型起名。
5. 顶部状态条只读已有 `gateway.snapshot`。门卫只认防封说明里的「已放行 / 出口正常」和「切断 / 出口不对 / 未放行」，红优先。额度取文案里「剩余 N%」的最小值。主机负载只认「负载 N%」或 CPU、内存、处理器百分数。对不上就写「暂无数据」，不把模拟 hello 画成绿灯，也不把只有进程号的说明画成正常。点击打开已有的「网关与监控」页。不新造计费后端，不读新的门卫文件，不采集 CPU。
6. 老人模式存在主机设置 `ui.elder`：`auto`、`on`、`off`，默认 `auto`。

   | 面板 | `auto` 时 |
   | --- | --- |
   | dad | 开 |
   | me | 关 |
   | 认不出 | 关 |

   手动开关写成 `on` 或 `off`，重新打开仍然有效。「恢复面板默认」写回 `auto`。面板认 `OPC_PANEL`，其次 Linux 用户 `dad` / `me`，再次家目录。客户端 `host.label` 只在服务端认不出时作精确回退。关掉模块「界面优化」后，状态条和放大一起卸下。
7. 老人模式的字号阶梯：手机宽度上标题 30、正文 22、行高 34、热区 56、间距 16。卡片墙的同意、打回等操作改为纵向排满行宽。非老人模式保持原来的字号和 44 高热区。任务页和笔记文件面板保持基础字号，不小于这个基础。布局断言用 360 宽，不代替真机。
8. 侧栏分区、排序和折叠跟分组用同一份配置，不另做一套侧栏逻辑。Paseo 0.14（`paseo-plugin.json` 要求 `>=0.14.0`）已在工具分组之前跑时间线 transformer，工具调用折叠不另做界面。插件补上的是「已完成」会话折叠。
9. 自有浅色主题「纸面」，id `opc-paper`。色值是本仓库自拟的：背景 `#f3f0e7`，正文 `#1c2430`，抬起 `#fffaf3`，控件 `#e4ebe4`，边框 `#c9d5cc`，强调 `#0b6b4f`，弱化 `#5e6a62`，环 `#7f9488`。不引入 Notion 主题包。
10. `m5-ui` 的清单改为 `enabled: true`，只读 `/home/br1efx/notes/cards/_ui/`，`write` 为空，不联网。外壳主机仍只有 `127.0.0.1` 和 `api.github.com`。`server/ui.ts` 的文件读取算在外壳上，外壳原本已声明读写。

### 三插件对照

没有读取这三个插件的源码，也没有复制实现。下表只记公开说明里的能力，以及本仓库自己写的对应物。本决定不卸载它们，也不改安装清单。

| 插件 | 记下的能力 | 本仓库 |
| --- | --- | --- |
| Sidebar Organizer（`pedrozimmermannsoares/sidebar-organizer`，`662d1e1`） | 会话按角色成组，可以置顶，能看出等你回复 | 显示名分组、折叠，等你的会话排在前面并标「· 等你」 |
| Title Style（`zwmmm/title-style`，基于 `1bb9e78`） | 自动起中文会话名；内存里记过的名字重启会重来 | 只做字重、颜色和前缀图标。不起名 |
| Better Paseo（`roundreddot/better-paseo`，`47fb489`） | 更紧的时间线、工具折叠、手机上更好点 | 吸收密度、可读和导航：老人模式把字和热区加大，列表更疏。工具折叠交给 Paseo 0.14。不重做任务看板 |

## 后果

- 分组文件要人自己放到卡片库 `_ui/`。插件没有写权限，不会代为创建。
- 状态条在模拟快照和缺字段时是「暂无数据」。真机上是否出现绿灯，取决于 Magpie 写进现有快照的防封说明，不取决于新的采集。
- 父亲手机上不用缩放就能点到主操作，仍需真机验证。`pnpm verify:mobile` 和性能测量保持 `DEFERRED`，不算通过。
- [0007](0007-d5b-opc-intake.md) 记下当时 m5 仍是 `enabled: false`。从本决定起，m5 只读分组目录并启用。
- 卸掉 Better Paseo、Sidebar Organizer、Title Style 要等 me 金丝雀之后另做，不在本决定里执行。
