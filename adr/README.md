# 架构决策记录（ADR）

一条 ADR 只记录一个已经做出的决定：当时有哪些约束、选定了什么、带来什么后果。实验数据写在 `docs/spikes/`，不写在这里。

## 文件

- 路径：`adr/NNNN-短标题.md`
- 编号四位，从 `0001` 起，不回收已用编号
- 状态写在文首：提议、已接受、已替代、已废弃
- 正文用这三节：背景、决定、后果
- 被后来的决定推翻时，改状态并指向新编号，不删旧文件
