# S2 · web.ts 里的 CodeMirror 6 和小弹窗

## 目的

架构页通过标准：电脑端能编辑，手机端只读且不报错。

## 环境

- `@getpaseo/plugin` 0.14.0
- CodeMirror：`@codemirror/view` 6.43.15、`state` 6.7.6、`commands` 6.11.1、`language` 6.13.1、`lang-markdown` 6.5.2
- 探针代码在 `plugins/opc-spike-peer/client/web.ts` 和 `client/popup.tsx`
- 没有 Paseo 桌面窗口，没有手机

## 做了什么

1. 按官方 markdown-panel 的做法，把 CodeMirror 放进 `client/web.ts`，用 `Platform.OS === "web"` 包住动态 `import()`。父节点类型是 `unknown`，没有写 `document`。
2. 侧边栏第二行调用 `openPopover(SpikePopup)`。弹窗组件只用 React Native 的 `View` / `Text`。
3. 用和插件相同的、没有 DOM 的 `tsc` 编译一份使用 `document` 的文件，预期失败。
4. 把探针插件装进临时 daemon。`status: running` 表示 `compileDirectoryPlugin` 编过 client 和 server。client 入口会进到 `web.ts`。

没有打开桌面编辑器，也没有在手机上打开只读页。

## 命令和输出

`pnpm --filter opc-spike-peer typecheck` 通过，包含 `client/web.ts`。

没有 DOM 库时，组件文件不能用 `document`：

```text
$ pnpm exec tsc --noEmit --strict --module ESNext --moduleResolution Bundler \
    --target ES2022 --lib ES2023 --skipLibCheck --jsx react-jsx \
    ../../docs/spikes/probes/s2-document-outside-web.tsx

error TS2584: Cannot find name 'document'. Do you need to change your target library?
Try changing the 'lib' compiler option to include 'dom'.
```

同一文件加上 `--lib ES2023,DOM` 后退出码 0。插件的 `tsconfig.json` 仍然不放 DOM，和 Paseo 脚手架一致。

临时 daemon 上：

```text
opc-spike-peer  status running
```

这只说明服务端加载前，编译器把 client 入口编过。没有界面进程，看不到编辑和只读。

## 结论

**PARTIAL**

编译这一段通过：无 DOM 的 `web.ts` 能挂上 CodeMirror 6，小弹窗能通过 `openPopover` 的类型检查，插件编译后能在 daemon 里就绪。

通过标准「电脑端能编辑，手机端只读不报错」：**UNKNOWN**。没有桌面，也没有手机。不记 PASS。
